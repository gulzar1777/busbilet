# Bus Ticket

**Bus Ticket** — C# və .NET istifadə edilərək hazırlanmış avtobus bilet sistemi layihəsidir. Layihənin əsas məqsədi avtobus biletlərinin daha rahat və sadə şəkildə idarə olunmasını təmin etməkdir.

## Layihə haqqında

Bu layihədə istifadəçilər üçün sadə və rahat interfeys hazırlanıb. Sistem vasitəsilə avtobus biletləri ilə bağlı əsas əməliyyatları yerinə yetirmək mümkündür.

## Əsas xüsusiyyətlər

* Avtobus biletlərinin idarə edilməsi
* Bilet sifarişi
* Sadə və istifadəçi dostu interfeys
* Rahat naviqasiya
* Asan istifadə

## İstifadə olunan texnologiyalar

* **C#**
* **.NET**
* **Visual Studio**

## Məqsəd

Bu layihə C# və .NET ilə proqramlaşdırma bacarıqlarını inkişaf etdirmək və real həyatda istifadə oluna biləcək sadə bir bilet sistemi yaratmaq məqsədilə hazırlanıb.
